# 정보보안팀 일정관리 대시보드

OK금융그룹 정보보안팀의 일정관리를 위한 웹 기반 대시보드입니다.

## 🎯 주요 기능

- **일정 직접 관리**: 캘린더에서 직접 일정을 추가, 편집, 삭제
- **평일 당직 자동 생성**: 팀원 순서를 입력하면 평일에만 자동으로 당직 배정 (주말/공휴일 제외)
- **사용자 정의 휴일**: 누락된 공휴일이나 회사 고유 휴일을 직접 추가 가능
- **팀원 명단 저장**: 로컬스토리지에 팀원 순서 자동 저장으로 매번 다시 입력할 필요 없음
- **캘린더 뷰**: FullCalendar 기반의 직관적인 월별 일정 표시
- **일정 유형 구분**: 연차, 반차, 당직, 회의, 외근/출장, 주간간담회, 월간간담회 등 색상별 구분 표시
- **일정 상세 보기**: 특정 날짜 클릭 시 상세 일정 정보 모달 표시
- **필터링**: 일정 유형별 필터링 기능
- **데이터 공유**: URL 링크를 통한 일정 공유 기능
- **백업/복원**: JSON 파일로 데이터 내보내기/가져오기
- **자동 저장**: 로컬 스토리지를 통한 자동 데이터 저장
- **반응형 디자인**: 데스크탑 환경에 최적화된 UI

## 🛠 기술 스택

- **Frontend**: React 18
- **UI Framework**: TailwindCSS
- **Calendar**: FullCalendar
- **Icons**: Lucide React
- **State Management**: React Hooks

## 🚀 실행 방법

### 1. 의존성 설치

```bash
npm install
```

### 2. 개발 서버 실행

```bash
npm start
```

브라우저에서 `http://localhost:3000`으로 접속하여 대시보드를 확인할 수 있습니다.

### 3. 프로덕션 빌드

```bash
npm run build
```

## 📅 공휴일 데이터

### 지원 범위
- **2024년**: 신정, 설날연휴, 삼일절, 어린이날, 석가탄신일, 현충일, 광복절, 추석연휴, 개천절, 한글날, 성탄절
- **2025년**: 신정, 설날연휴, 삼일절, 어린이날, 석가탄신일, 현충일, 광복절, 추석연휴, 개천절, 한글날, 성탄절

### 특징
- **네이버 캘린더 기준**으로 대한민국 공휴일 데이터 반영
- **대체공휴일** 자동 포함
- **사용자 정의 휴일** 추가 기능으로 누락된 공휴일이나 회사 고유 휴일 보완
- **평일 당직 생성 시 자동 제외**
- 음력 기준 공휴일(설날, 추석, 석가탄신일) 양력 날짜로 변환 적용
- **요일 검증**: 정확한 주말(토요일=6, 일요일=0) 계산으로 평일만 선별
- **시간대 문제 해결**: 정오(12시) 기준 날짜 생성으로 시간대 오류 방지
- **캘린더 순서**: 월요일 시작(월~일) 형태로 직관적인 주간 표시

## 📖 사용법

### 1. 일정 추가
- 대시보드에서 **"일정 추가"** 버튼 클릭
- 이름, 일정 유형, 날짜를 입력
- 필요 시 설명 추가 후 **"추가"** 버튼 클릭

### 1-1. 평일 당직 자동 생성 🛡️
- **"당직 넣기"** 버튼 클릭
- 팀원 이름을 순서대로 입력 (기본: 김보안, 이감사, 박관제, 최보안)
  - **자동 저장**: 팀원 목록은 로컬스토리지에 자동 저장되어 다음에도 유지됨
- 연도와 월 선택 (캘린더는 **월~일** 순서로 표시)
- 팀원 순서 조정 (↑↓ 버튼 사용)
- **추가 휴일 설정**: 회사 고유 휴일이나 누락된 공휴일 직접 추가
- **미리보기 확인**: 통계와 실제 배정 결과 미리 확인
- **"당직 일정 생성"** 클릭하면 해당 월 **평일에만** 자동 배정
- **주말(토,일)**과 **모든 공휴일**은 자동 제외
- 당직 일정은 **🛡️ 아이콘**과 함께 **날짜 맨 앞**에 표시

### 2. 일정 편집/삭제
- 캘린더에서 특정 날짜 클릭
- 일정 목록에서 **"편집"** 또는 **"삭제"** 버튼 클릭

### 3. 일정 필터링
- 상단 필터에서 보고 싶은 일정 유형 선택
- "전체", "연차", "반차", "당직", "회의", "외근/출장", "주간간담회", "월간간담회" 중 선택

### 4. 데이터 공유
- **"공유"** 버튼 클릭
- URL 복사하여 다른 사람과 공유
- 또는 JSON 파일로 내보내기/가져오기

### 5. 데이터 백업
- 공유 모달에서 **"JSON 파일 다운로드"** 클릭
- 로컬 스토리지에 자동 저장되므로 브라우저를 닫아도 데이터 보존

## 📋 주요 기능 사용법 요약

| 기능 | 방법 |
|------|------|
| **일정 추가** | 우상단 "일정 추가" 버튼 → 정보 입력 |
| **평일 당직 자동 생성** | 🛡️ "당직 넣기" 버튼 → 팀원 순서 입력(자동저장) → 추가 휴일 설정 → 월 선택 |
| **일정 편집** | 캘린더 날짜 클릭 → "편집" 버튼 |
| **일정 삭제** | 캘린더 날짜 클릭 → "삭제" 버튼 |
| **데이터 공유** | "공유" 버튼 → URL 복사 또는 JSON 다운로드 |
| **필터링** | 상단 드롭다운에서 일정 유형 선택 |
