## 제품 상세 설명

하이브리드 근무 환경의 정보보안(InfoSec) 팀 (약 15 명)을 위해 **실시간 일정 공유 웹앱**을 제공한다.

* **단일 진실 공급원(Single Source of Truth)**: 스프레드시트·개별 캘린더 분산 문제를 해소
* **즉시 동기화**: Supabase Realtime 채널을 활용해 변경 사항을 1 초 이내 전파
* **배포 용이성**: Vercel Free Tier에 올인—빌드/롤백 단순화
* **내부 전용**: 회사 이메일 도메인 기반 인증·권한 관리
* **출력 편의**: 월간 PDF 다운로드 기능으로 팀·임원 보고 시 작업 절감

> **예시 이미지 콘셉트 제안**
>
> 1. 월간 캘린더 뷰(다크·라이트 토글)
> 2. ‘새 이벤트’ 모달(자연어 Quick-Add 입력창 포함)
> 3. PDF 미리보기 오버레이

## 핵심 기능 및 세부 명세

### 1. 실시간 공동 캘린더

* **설명**: Supabase Realtime 구독으로 모든 클라이언트에 `≤1 s` 내 변경 전파
* **권한**: 로그인 사용자 누구나 CRUD, 단 **Row-Level Security**로 이메일 도메인 검증
* **성공 지표**: 충돌(동일 슬롯 중복) 발생률 90 %↓

### 2. “PDF로 다운로드” 버튼

* **라이브러리**: `pdf-lib` (클라이언트)
* **출력 범위**: 기본 월간, 주간·리스트 옵션 추가
* **접근성**: 오프라인 보고용; 팀원 80 % 이상 월 1회 사용 목표

### 3. 한국 공휴일 자동 삽입

* **데이터 소스**: Naver Calendar Open API (REST)
* **캐싱**: 월 단위 SSG 재생성 + Supabase `holidays` 테이블

### 4. 평일(on-call) 로스터 자동 생성

* **로직**: 팀원 목록 라운드로빈, 주말·공휴일 skip
* **UI**: “로스터 미리보기 & 확정” 버튼 → 이벤트 일괄 생성

| 요구 KPI       | 목표 값            |
| ------------ | --------------- |
| 팀 전체 채택률     | 100 % (1 개월 이내) |
| 일정 충돌 감소     | ≥ 90 %          |
| 실시간 전파 지연    | ≤ 1 s           |
| 월간 PDF 다운로드율 | ≥ 80 %          |

## 사용자 페르소나 및 시나리오

### 페르소나

| 구분 | 상세                                 |
| -- | ---------------------------------- |
| 이름 | 김보안 (35세, 선임 엔지니어)                 |
| 동기 | 교대 근무·긴급 대응 일정 누락 방지               |
| 좌절 | 스프레드시트 버전 충돌, 휴일 누락으로 인한 과로        |
| 목표 | 한 화면에서 팀·개인 일정을 즉시 확인, PDF로 리포트 제출 |

### 주요 시나리오

1. **새 근무표 작성**

   * 김보안은 “로스터 생성” 클릭 → 1개월 평일 자동 할당 → 저장 시 팀원 화면 즉시 반영
2. **휴가 반영**

   * 휴가 신청 승인 시 개인 캘린더에 ‘연차’ 이벤트 자동 생성, 겹치는 on-call 당직은 다음 순번으로 이동
3. **PDF 공유**

   * 월말, 매니저가 “PDF 다운로드” → 임원 회의자료 첨부

## 기술 스택 권고사항

| 계층           | 선택 기술                                | 이유                              |
| ------------ | ------------------------------------ | ------------------------------- |
| **프런트엔드**    | Next.js 14 (App Router) + TypeScript | 파일 기반 라우팅·서버 컴포넌트로 데이터 패칭 최적화   |
| **UI**       | Tailwind CSS + Shadcn-UI             | 빠른 프로토타이핑·다크 모드 내장              |
| **실시간 & DB** | Supabase (PostgreSQL + Realtime)     | 무료 티어에서 실시간 채널 제공·RLS 지원        |
| **배포**       | Vercel Free Tier                     | Git 통합·프리뷰 브랜치·SSL 기본           |
| **외부 API**   | Naver Calendar API                   | 국내 공휴일 신뢰성 확보                   |
| **PDF 생성**   | pdf-lib (브라우저)                       | 서버 부하 없이 클라이언트 변환               |
| **보안**       | Supabase JWT, HTTPS 전면 강제            | 내부 이메일 도메인 화이트리스트·GDPR 유사 감사 로그 |

> **Note:** Supabase Free Tier의 DB Row/대역폭 한도(현재 500 MB / 2 GB 전송) 초과 가능성 대비, 월간 백업 & 아카이빙 전략 필요.
> **Note:** Vercel Hobby 플랜은 월 100 GB Bandwidth 제한—PDF 대량 다운로드 시 주의.

### 문서 작성 시 참고 사항

* DB 설계는 추상 레벨(예: `events`, `roster`, `holidays` 테이블 존재 여부만)로 유지
* 디자인 산출물 작성 시 **샘플 이미지** 삽입을 적극 권장(피그마, 화이트보드 스케치 등)
* 모든 일정 데이터는 **PII 최소화** 원칙 준수: 이메일 외 개인 정보 저장 금지
